string-diagrams

String diagrams in LaTeX, drawn with TikZ.

You put boxes and dots in a TikZ picture. Then you write a list of wires. The \wires command draws the wires and their loose ends at the edge of the picture.

Manual CTAN GitHub

Live demo

You can change the code of each example. Click Compile to draw the picture again. TeX operates in your browser.

Getting started

The package is on CTAN and in TeX Live. Put this line in the preamble of your document. The package loads TikZ.

\usepackage{string-diagrams}

The examples need version 0.3 or later. To update an older version, use tlmgr update string-diagrams. You can also put string-diagrams.sty in the folder of your document. The Open in Overleaf buttons do this.

A diagram is a usual tikzpicture. Boxes and dots are TikZ nodes, and you can put them in any position. The \wires command connects them. Each wire goes out of a side, a corner or a port in the correct direction. A wire can also go to the edge of the picture, which is the boundary node @.
